Cloud computing · Virtualisation

Howcanonecomputerbemany?

HOW IT WORKS

A hypervisor splits one machine.

Each virtual machine acts like a real computer, sharing the same hardware.

1960s · ORIGINS

Share the giant.

IBM's CP-67 let many users work on one mainframe.

1970s–80s · DECLINE

The quiet years.

Cheaper PCs replaced shared mainframes. Research slowed.

LATE 1990s · REVIVAL

Back in business.

VMware brought virtualisation to everyday x86 servers.

2000s · MAINSTREAM

Fewer servers, same work.

Data centres consolidated, saving cost, space and energy.

2010s · CLOUD ERA

Then came the cloud.

AWS, Azure and Google Cloud are built on it.

One machine. Many computers.

That's virtualisation, and the cloud runs on it.
